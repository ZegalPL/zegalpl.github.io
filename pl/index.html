Zakres usług

Projektujemy i utrzymujemy środowiska AWS (EC2, IAM, EKS, ECS, RDS, S3, API Gateway) dla systemów krytycznych. Wdrażamy architektury multi-region i poprawiamy bezpieczeństwo.

Budujemy i prowadzimy platformy kontenerowe end-to-end: od obrazów i pipeline'ów po produkcyjne klastry Kubernetes (EKS/ECS, Karpenter, Rancher, OpenShift).

Automatyzujemy proces od commita do wdrożenia w Jenkins, GitHub Actions i GitLab CI, również dla środowisk o bardzo dużej skali.

Infrastructure as Code z Terraform i Terragrunt, wspierane przez Ansible i Flux. Dostarczamy moduły, standardy i procesy GitOps.

Wdrażamy praktyki SRE: SLO/SLA, error budgets i runbooki. Szczególnie dobrze odnajdujemy się w środowiskach regulowanych.

Budujemy observability oparte o CloudWatch, Datadog, Grafana i Prometheus. Konfigurujemy alerting i on-call (PagerDuty).
